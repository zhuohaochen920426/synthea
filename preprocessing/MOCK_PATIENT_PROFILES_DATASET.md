# Synthetic patient profiles (308 patients)

Mock electronic health record (EHR) profiles for patient-agent interaction experiments.
Every patient is **fully synthetic**, generated by the open-source
[Synthea](https://github.com/synthetichealth/synthea) simulator. No real patient data was
used. Names, SSNs and other direct identifiers are not included in this dataset.

## Files

| File | Format |
|---|---|
| `patients_final.jsonl` | one JSON object per line; list fields are real lists |
| `patients_final.csv` | one row per patient; list fields flattened to text separated by ` \| ` |

Both files have the same 308 patients and the same 16 columns in the same order.

## Population

- **308 patients**, aged **28 to 89**, 160 F and 148 M.
- Race: white 198, black 50, asian 23, hawaiian 15, other 11, native 11.
  Ethnicity: nonhispanic 258, hispanic 50.
- Marital status: M 192, S 60, D 40, W 16.
- 12 US states, 22 to 29 patients each (Massachusetts, California, Texas, Mississippi,
  New York, Alaska, Hawaii, Florida, Arizona, Illinois, Georgia, Washington).
- 6 are currently pregnant.
- All are treated as alive. Ages are as of **2026-11-15**.

Because children and patients with a missing marital status were removed, the dataset
contains adults only and is skewed to middle age and older.

## Columns

| Column | Type | Meaning |
|---|---|---|
| `patient_id` | string | Synthea patient UUID |
| `age` | int | Age in years on 2026-11-15 |
| `marital` | string | `M` married, `S` single, `D` divorced, `W` widowed |
| `race` | string | white, black, asian, hawaiian, native, other |
| `ethnicity` | string | hispanic, nonhispanic |
| `gender` | string | `M` or `F` (Synthea's recorded gender) |
| `city`, `state` | string | Home location |
| `pregnancy_status` | string | `pregnant`, `not pregnant`, or `not applicable` (male patients) |
| `health_problems` | list | Diseases, each with a status. Ongoing ones, plus those resolved in the last 2 years. |
| `encounters` | list | The 5 most recent distinct visit types, each with its last date |
| `medication_details` | list | Medications the patient is **currently on**, with the reasons they were prescribed |
| `allergies` | list | Allergy and intolerance names (possibly empty) |
| `careplan_details` | list | **Ongoing** care plans, with reasons |
| `procedures_detail` | list | Notable procedures from the last 10 years (up to 8), with occurrence count and last year |
| `observations_summary` | string | One short text: latest vitals, key labs, tobacco and stress, and flags |

### Field formats

**JSONL**

```json
{"patient_id": "...", "age": 46, "marital": "S", "race": "white", "ethnicity": "nonhispanic",
 "gender": "M", "city": "Shutesbury", "state": "Massachusetts", "pregnancy_status": "not applicable",
 "health_problems": [{"description": "Primary dental caries", "status": "resolved"}],
 "encounters": [{"description": "Encounter for check up", "last_date": "2025-05-06"}],
 "medication_details": [{"description": "Acetaminophen 325 MG Oral Tablet [Tylenol]", "reasons": []}],
 "allergies": [],
 "careplan_details": [{"description": "Therapy", "reasons": []}],
 "procedures_detail": [{"description": "Dental care", "occurrences": 5, "last_year": 2025}],
 "observations_summary": "Vitals (2026-04-28): BP 147/84 mmHg; ..."}
```

**CSV** (same content, flattened)

| Column | Example |
|---|---|
| `health_problems` | `Anemia [ongoing] \| Sprain of ankle [resolved]` |
| `encounters` | `Encounter for check up [2025-05-06]` |
| `medication_details`, `careplan_details` | `lisinopril 10 MG Oral Tablet for: Essential hypertension` |
| `allergies` | `Mold \| Aspirin` |
| `procedures_detail` | `Colonoscopy [2x, last 2023]` |

### Example `observations_summary`

> Vitals (2026-04-28): BP 147/84 mmHg; HR 64/min; RR 13/min; temp 37.1 °C; BMI 30.5 kg/m2;
> weight 86.5 kg; height 168.4 cm; pain 2/10. Labs (2024-04-16): total cholesterol
> 222.2 mg/dL; LDL 149.5 mg/dL; HDL 47.5 mg/dL; triglycerides 125.8 mg/dL; hemoglobin
> 15.7 g/dL. Social: tobacco: Never smoked tobacco; stress: Not at all. Flags: high blood
> pressure; obese BMI

The `Flags:` part appears only when a value crosses a threshold: blood pressure ≥ 140/90,
BMI ≥ 30 or < 18.5, HbA1c ≥ 5.7 (prediabetic) or ≥ 6.5 (diabetic), LDL ≥ 160, eGFR < 60.
**These thresholds were chosen by the dataset builder and are not from Synthea.**
Which vitals and labs are present depends on the patient. Missing ones are left out.

## Things to know before using it

- **Synthetic, not clinical truth.** Records follow Synthea's rules and statistics. Do not
  draw clinical conclusions from them.
- **Clinician language, not patient language.** Entries are standard terms (SNOMED, RxNorm,
  LOINC names) with type tags removed. There is no chief complaint, symptom story or name.
  An agent playing a patient has to turn these into everyday language.
- **Current vs past.** Medications and care plans are current only. Health problems mix
  ongoing and recently resolved, so check the `status`.
- **Status comes from the data.** "ongoing" means the record's stop date was blank or after
  2026-11-15. Nothing is simulated by the dataset builder.
- **Summaries are partial.** Only the 5 latest encounter types, up to 8 notable procedures
  and the latest value of a few observations are kept. Routine screenings and surveys are
  left out.
- **Dental care is common** in `procedures_detail`.
- **Short history.** Synthea exports only about the last 10 years of each record.
- **Empty lists are normal.** Many patients have no allergies, no ongoing care plan, or no
  ongoing medication (54 patients).
